## 1. pandas pickle 缓存跨版本不可读

**现象**：复用 `example/.cache/*.pkl` 时，默认 Python / pandas 可能报
`NotImplementedError: (<StringDtype(...)>, array([...]))`，导致回测还没开始就失败。

**根因**：`pd.to_pickle` 生成的缓存不是稳定的跨版本数据格式。不同 Python / pandas
组合在 dtype 反序列化上可能不兼容，尤其是用旧环境写缓存、再用新环境读取时。

**标准解法**：优先在同一虚拟环境中读写缓存；若环境已变化，删除对应 `.cache/*.pkl`
并用聚宽凭证重新拉取数据。不要为了绕过缓存错误去修改固定评估器或基线口径。

## 2. 本地回测「当日收盘成交」比聚宽乐观（8pp 缺口）

**现象**：同一份策略、同一段区间，本地 holdout 总收益 +20.62%，复制到聚宽平台实测
只有 +12.28%，差 8pp；且聚宽日志出现「下单数量为 0 / 开仓数量不能小于 100」等报错。

**根因**：两处口径不一致，叠加后被单次大行情放大。

1. **成交时点**：本地用「当日收盘价」成交，等于假设「收盘看到信号、当天就以收盘价
   买到」——这吃到了**当天到次日的隔夜跳空**。聚宽是事件驱动，`market_open` 里下的单
   在**次日开盘**成交，吃不到跳空。2024-09-24 那波暴涨里，510300 次日高开近 8%，
   本地收盘成交把这段跳空算成了自己的收益，聚宽则没有。这是 8pp 缺口的主因。
2. **导出脚本缺幂等门控**：`market_open` 每个交易日都无条件 `order_target_value`，
   已满仓还重复下单 → 数量算成 0 或不足 100 股 → 满屏报错、且产生本地没有的日内微调。
3. 整手（100 股）、滑点、T+1、真实价+现金分红等实盘约束，本地默认都没模拟。

**标准解法**：

- **导出层**：`scripts/export_jq.py` 的 `market_open` 加幂等门控——`buy` 仅在
  `position == 0` 时下单、`sell` 仅在 `position > 0` 时清仓（已修复）。
- **评估器层**（经用户一次性授权改固定评估器后冻结）：`backtest.py` 撮合改为
  **当日收盘算信号、次日开盘成交**，并加 100 股整手 + 聚宽默认滑点
  `PriceRelatedSlippage(0.00246)`；次日开盘成交下 T+1「买入当日不可卖」天然满足。
- **验证**：对齐后同段本地 holdout +12.52% ≈ 聚宽 +12.28%（差 0.24pp），缺口消除。
- **残差（已知、可接受）**：本地仍用腾讯前复权价（分红按比例再投资隐含在价里），
  聚宽用真实价 + 现金分红，二者在除权日附近有二阶差异；对低频择时影响远小于成交
  时点，暂不追平。

**通用教训**：凡「收盘看到信号、就用收盘价成交」的回测都自带乐观偏差，趋势/动量类
策略尤甚（信号常出现在启动日，隔夜跳空全被算给自己）。**信号与成交必须错开至少一根
bar**（次日开盘或次日收盘），否则本地分数天然虚高、无法迁移到实盘/聚宽。

**已固化**：`example/backtest.py` `_simulate`（次日开盘撮合 + 整手 + 滑点）；
`scripts/export_jq.py` 幂等门控模板。

## 3. 横截面 v2 外部数据源间歇不可用

**现象**：`scripts/fetch_universe.py` 报 EastMoney「Empty reply」；`load_panel()` /
`_fetch_page` 报腾讯 HTTP 501；全窗口基线跑不通。

**根因**：

- EastMoney `push2.eastmoney.com` 在部分网络/沙箱环境直接断连；
- 腾讯财经 kline 接口有频控/临时 501，批量拉 300 股时更易触发；
- 沪深300 指数在腾讯侧符号为 `sh000300`，不能用 `_tencent_symbol("000300.XSHG")`
  （会误映射为 `sz000300`）。

**标准解法**：

- **成分快照**：`fetch_universe.py` 已内置新浪 `hs300` 分页备用源（EastMoney 失败时
  自动降级）；仍失败则**停止**，不要手编清单。
- **基准符号**：`backtest_xs.load_panel` 基准固定用 `"sh000300"`。
- **面板缓存**：首次成功拉取后写入 `example/.cache/panel_csi300_*.pkl`，后续读缓存；
  501 期间无缓存则基线登记阻塞，等接口恢复再跑 `python backtest_xs.py`。
- **终验**：本地数据源阻塞不影响聚宽 `jq_strategy_xs_export.py` point-in-time 终验。
